# Bookconverter Android v1.0.0

## O que mudou
- **Tradução resiliente e fila serial (P2):** checkpoints atômicos por bloco no Room, pausar/retomar/cancelar, WorkManager + Foreground Service `dataSync`, espera por rede/429/orçamento e fila FIFO de múltiplos livros.
- **Séries, glossário e tradução rápida (P3):** criação de séries, notas de estilo, glossário manual e `.txt` do desktop (`→`/`->`), janela **Traduzir texto** (colar texto e exportar em TXT, DOCX, PDF e MD).
- **Revisão e exportação EPUB pt-BR (P4):** comparador lado a lado, edição manual, retradução de bloco, exportação validada só pt-BR (sem tocar no original) e compartilhamento via `FileProvider` + melhorias de acessibilidade (AC15).
- **MOBI / AZW3 sem DRM (D1):** integração da `libmobi` via NDK (`arm64-v8a` e `x86_64`) com recusa de DRM e conversão interna para EPUB.
- **Memória de série por IA + RAG (D2/D5):** extração de termos, personagens e pares EN↔PT com trecho original, detecção de conflitos e seleção semântica local (TF-IDF + trigramas).
- **Modo econômico Batch API + Backup manual + Extras (D3/D4/D5):** Batch API para OpenAI, Anthropic e Gemini; backup/restauração `.zip` (sem chaves); adaptador OpenRouter/genérico; tema AMOLED Escuro, Claro e Sistema; exportação de livros completos em DOCX e PDF.
