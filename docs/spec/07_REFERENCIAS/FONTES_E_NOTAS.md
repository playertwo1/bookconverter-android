## Limitações dos exemplos e imagens
- Todos os livros, séries e termos usados no mockup individual são inventados e ilustrativos.
- Modelo / esforço do mockup não equivale a disponibilidade de API real; verificar a documentação e a conta do usuário no momento da implementação.
- Fontes SF Pro / New York de iOS são só referência de estilo, não distribuídas neste pacote. PNGs de referência não são componentes editáveis.
- Capturas iOS-style são apenas conceito estético aplicado ao produto Android.
- Os mockups e documentos foram produzidos para especificação; não representam um APK funcionando.
