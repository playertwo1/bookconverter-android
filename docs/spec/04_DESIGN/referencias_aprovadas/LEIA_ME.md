# Proveniência das referências
- `Referencia_visual_usuario.jpg`: imagem de referência fornecida pelo usuário; copiar elementos de hierarquia e atmosfera, não capas protegidas.
- `Conceito_*.png`: conceitos visuais apresentados na conversa e/ou novos painéis gerados para esta documentação. Podem conter textos ilustrativos e inconsistências típicas de imagens generativas; use as telas 01–23 do catálogo para especificação precisa.
- `screens/01...23`: mockups de fluxo sistemáticos criados para o pacote com tokens e rotulagem controlada. Nenhum é uma captura do app implementado.
